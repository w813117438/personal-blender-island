# 智能旋转模式转换

物体和姿态骨骼的变换面板中，旋转模式下拉菜单现在执行动画转换，而非只改变当前姿态的表示方式。属性面板使用相同入口。下拉菜单只处理该面板对应的物体或骨骼；搜索菜单中的“转换旋转模式”仍处理选中项。

转换保留原关键帧时间，包括负帧和小数帧。算法仅在原关键帧之间的整数帧位置采样旋转轨迹，以约 0.05 度的采样误差阈值精简补点；只有必要的点会写入动画，不逐帧插满。新增点标记为分解帧，并且只落在整数帧上；已有小数帧关键帧保持原位。转换后的连续区间使用线性插值，以保持精简时验证的插值结果，因此原曲线控制柄不逐一保留。

支持欧拉旋转顺序、四元数和轴角之间转换，并处理四元数符号连续性、欧拉角连续性和轴角整圈旋转。简单静止或匀速动画保留很少的点，复杂运动可能需要更多点。误差检查针对整数帧，不保证子帧轨迹完全一致，也不保证恢复单帧内发生的任意极高频运动。

含旋转驱动器、F-Curve 修改器、采样曲线、线性外推、被动画控制的旋转模式或不可编辑动作时，会取消操作并提示原因，避免静默丢失原动画。约束与父级保持原样；此功能转换局部旋转曲线，并不烘焙约束。

修改可撤销。脚本直接赋值 `rotation_mode` 保留 Blender 原有语义，以免动画求值或现有脚本意外改写动作；自动转换由界面的下拉菜单执行。

测试：`tests/python/smart_rotation_conversion.py`。
