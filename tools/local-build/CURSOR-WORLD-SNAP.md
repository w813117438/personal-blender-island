# 游标双向世界变换吸附

物体模式或姿态模式下，在“物体／姿态 → 吸附”菜单或 Shift+S 吸附菜单中选择：

- **游标 → 选中项（世界位置和旋转）**：单选时复制物体求值后的世界位置和世界旋转，包含父级和约束结果。多选时，位置沿用原“游标到选中项”的世界中心计算方式，旋转取活动选中物体（最后选中的物体）。
- **选中项 → 游标（世界位置和旋转）**：每个选中物体的原点移动至游标的世界位置，并对齐游标的世界旋转。保留物体缩放属性，尊重变换锁定。父物体先处理，子物体使用更新后的父级矩阵计算局部变换；同时处理父级逆矩阵及增量变换。

姿态模式也支持这两项操作：

- **游标 → 选中项**：位置取选中骨骼头部的世界中心，旋转取活动骨骼求值后的世界旋转，包含骨架物体变换、父骨骼和约束结果。支持多个骨架同时处于姿态模式。
- **选中项 → 游标**：每根选中骨骼的头部及朝向对齐游标的世界变换。按父骨骼到子骨骼的顺序处理，并将世界目标转换为骨架空间和骨骼局部空间。保留骨骼缩放、静止姿态、连接关系及变换锁定，支持自动关键帧。

吸附会检查约束求值后的最终世界位置和旋转。初始矩阵换算无法精确对齐时，通过局部位置和旋转的数值校正求解，包含中间约束权重、父级变换及锁定的实际影响。Child Of 的权重不再限制为 1；完整 Child Of 仍使用逆矩阵补偿加速。约束的目标、权重、Set Inverse 矩阵及缩放属性保持不变。

成功要求世界位置误差小于 `0.00001` 个场景单位、旋转误差小于 `0.0001` 弧度。相连骨骼、锁定、完全覆盖姿态的约束或无法收敛的约束组合可能阻止达到目标：此时取消操作，恢复整个选择的原始变换，不插入新关键帧，不留下部分吸附结果。

原来的仅位置吸附操作继续保留。新菜单项只在物体模式和姿态模式显示，不修改编辑模式下的静止骨架。

这是一次性吸附。之后修改权重或目标变换，需重新执行吸附；它不会持续锁住骨骼的世界位置和旋转。成功操作可以撤销。

源码重新编译后生效，已经打开的 Blender 进程需要保存工作并重新启动。

回归测试（在项目根目录执行）：

```powershell
& .local-build/build-full/bin/Release/blender.exe --background --factory-startup --python-exit-code 1 --python tests/python/view3d_cursor_world_snap.py
```

启用 Python 测试的 CMake 构建也注册了 `view3d_cursor_world_snap` 测试。
