# 手指 Picker

内置在 3D 视口侧栏：按 **N → 手指选择 → 手指 Picker**。未选骨架时入口仍然可见，并提示选择骨架；选择骨架后，可在面板进入姿态模式。此页签名称不会再被翻译成“孤岛”。

## 绑定

1. 开启 **绑定模式**。
2. 点击左手或右手某根手指的 **1／2／3** 按钮。
3. 在弹窗搜索并选择控制骨骼，确认。弹窗默认使用当前活动骨骼；留空确认可清除该位置的绑定。
4. 关闭绑定模式，开始使用 Picker。

每只手有五指，每指三个位置；1、2、3 默认表示根节、中节、末节，也可绑定任何自定义控制骨骼。不依赖骨骼命名规则，不要求模型使用特定绑定系统。

## 选择

- 点击数字按钮：选择一个绑定骨骼。
- 点击手指名称：选择这一指已绑定的骨骼。
- 点击 **选择整手**：选择这一手已绑定的骨骼。
- **Shift 点击**或开启 **加选**：保留原选择并添加。
- **Ctrl 点击**：从选择中移除。

选择仅作用于当前活动骨架。隐藏骨骼、隐藏的骨骼集合及禁止选择状态受到保护。没有有效目标的按钮不会清掉原选择。选中状态会显示在按钮上。

绑定按骨架物体分别保存，随 `.blend` 文件保存和重新打开；复制物体后绑定可独立修改。骨骼重命名后需要重新绑定对应位置，失效绑定会显示错误标记。

本面板只选择骨骼，不修改位置、旋转、缩放，也不插入关键帧。回归测试位于 `tests/python/finger_picker.py`。
