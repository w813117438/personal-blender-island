# 摄影表变换轨道与控制柄倍率

摄影表和动作编辑器将同一物体或骨骼、同一属性的动画曲线显示为可折叠的父轨道：位置、旋转、缩放。父轨道汇总各轴关键帧，展开可编辑独立轴。四元数包含 W/X/Y/Z；轴角旋转包含角度和 X/Y/Z。曲线编辑器保留原有显示方式，动画曲线与动作分组本身不被重排或改名。

在 3D 视图中右键移动、旋转或缩放控制柄，或右键左侧对应工具图标，可调整：

- **控制柄速度倍率**：鼠标拖动灵敏度，范围 0.1–1，1 为原始速度。
- **控制柄大小倍率**：控制柄显示尺寸和对应点击区域，范围 1–2，1 为原始大小。此项不改变物体尺寸。

这两个倍率由变换控制柄共享，保存在用户偏好中。旧偏好未包含这两个字段时按 1 倍读取；原有键位设置保持不变。键盘直接发起的 G/R/S 以及数字输入保持原有行为。

手动验证建议：

1. 给物体的位置、旋转、缩放分别插入关键帧，确认摄影表出现三个父轨道。
2. 展开父轨道查看轴，折叠后选择汇总关键帧并移动，确认对应各轴同步移动。
3. 切换曲线编辑器，确认轴曲线仍分别显示。
4. 右键变换工具，设置大小为 2，确认控制柄放大而物体不变。
5. 分别用 0.1、0.5、1 倍速度拖动移动、旋转、缩放控制柄，检查灵敏度。
6. 保存偏好并重新打开，确认倍率和 Blender 2.79 键位保持。

曲线编辑器现在按通道选择显示曲线：单选显示该通道，多选显示所选通道；选择分组显示该组曲线，没有选中通道时不显示曲线。左侧通道列表保持完整，手动隐藏的曲线仍保持隐藏。关键帧选择与编辑遵循同一可见性筛选，摄影表不受此筛选影响。可运行 `tests/python/graph_selected_channels.py` 验证这些行为。
