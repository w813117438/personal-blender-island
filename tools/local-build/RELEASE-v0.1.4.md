# blender-island v0.1.4 — 中间帧默认同步全部通道

修复中间帧工具在曲线编辑器左侧只选中一个轴时，其他轴的关键帧没有一起移动的问题。
v0.1.4 是此次发布包的修订号，基于 Blender 5.3.0 Alpha，程序内部品牌名称仍显示 blender-island v0.1。

## 更新内容

- 默认范围改为 **选中物体 / 骨骼**。在时间轴、摄影表、曲线编辑器和 3D 视口中，所选物体或姿态骨骼的全部动画通道一起调整时间。
- 左侧通道选择、曲线独显、曲线隐藏及编辑器过滤不再缩小默认操作范围。例如左侧只选中 X 轴时，所选物体或骨骼的 Y、Z 轴关键帧仍会一起移动。
- 需要按当前显示曲线操作时，可手动选择 **按编辑器筛选**，保留此前的编辑器过滤行为。
- 姿态模式仍只处理选中的骨骼，包含这些骨骼的自定义属性；未选中的骨骼不受影响。锁定曲线、锁定通道组和只读动作仍会跳过。
- 旧文件中保存的默认范围会采用新的全部通道行为，保存的 **整个场景** 范围保持原有含义。

保留插入／移除空白帧、所选关键帧之间逐段调整、撤销／重做，以及此前的手指 Picker 和其他自定义动画工具。

## 下载使用

下载 `blender-island-v0.1.4-windows-x64.zip`，完整解压后运行 `blender-island.exe`。
中间帧入口位于时间轴、摄影表、曲线编辑器顶栏的 **中间帧**，或 **N → 动画工具**。
程序和内置脚本已包含在包内，无需额外安装插件。

使用 Blender 默认操作方案和干净的出厂偏好，独立配置保存在 `portable/config`。
附带 `.sha256` 校验文件，包内 `version.json` 记录完整源码提交、编译标识和程序 SHA256。
详细用法见 `docs/INBETWEEN.md`。

## 使用范围与验证

中间帧工具处理活动 Action 的 F-Curve 关键帧，不调整 NLA 条带、驱动器、蜡笔曝光帧、音频、时间标记或播放范围。NLA 微调模式会取消操作。
共享同一动作槽位的物体仍共享修改，与 Blender 原有共享数据行为一致。

发布前验证默认范围在单轴独显和编辑器过滤下同步全部通道、选中骨骼与物体隔离、锁定保护、旧文件范围兼容性及撤销／重做，并运行原有功能回归测试。
发布包同时检查独立启动、默认 Blender 键位、内置脚本与源码一致性、编译提交标识和 ZIP 的逐文件 CRC 完整性。
