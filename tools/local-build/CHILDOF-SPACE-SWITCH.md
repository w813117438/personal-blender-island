# 子级约束空间切换（Space Switch）

内置在源码的 `scripts/startup` 中，作用于 Blender 原生 **子级约束（Child Of）**，在切换权重时保持物体或姿态骨骼当前求值后的相对世界位置与旋转，不改动约束的逆矩阵（`Set Inverse`），兼容原版 Blender 打开与常规动画导出。

## 界面入口与触发方式

- **直接拖动 / 输入原生「影响（Influence）」滑条或点击右侧 `×`（停用并保持变换）**：默认开启 **拖动“影响”自动保持空间**，无论直接在约束面板拖动权重滑条、输入数值，还是点击原生 `×` 按钮，都会自动反解局部位置与旋转以保持世界变换；当角色已有动画或开启自动插帧时，还会同步写入 `CONSTANT` 权重关键帧与 `t - 1` 保护帧，防止前序动画漂移。
- **属性编辑器 → 物体约束 / 骨骼约束 → 子级（Child Of）面板**：在影响权重下方直接提供 **空间切换（保持世界变换）** 控件，完整保留原有的设置逆矩阵、清除逆矩阵、轴向开关等原生按钮。
- **3D 视口 / 摄影表 / 曲线编辑器 → N 侧栏 → 动画工具 → 子级约束空间切换**：集中列出当前活动物体、活动姿态骨骼以及框选姿态骨骼上的所有子级约束，支持外部关联骨架的 **库重写（Library Override）** 角色直接一键切换。

## 操作说明

- **跟随 (1)**：将当前子级约束权重设为 `1`，反解局部变换以保持当前世界位置与旋转。
- **松开 (0)**：将当前子级约束权重设为 `0`，保留脱离瞬间的世界位置与旋转。
- **接管跟随**（当同一物体或骨骼存在 2 个及以上启用中的子级约束时自动显示）：将当前子级约束设为 `1`，同时将其余子级约束同步归 `0`，一步完成多父级无损交接（如左手交右手、右手放桌面）。
- **全部子级约束松开归 0**：将同一物体或骨骼上的所有启用子级约束一键归 `0` 并保持世界变换。
- **目标权重 + 应用**：支持切换到 `0 ~ 1` 之间的任意中间权重（结合数值校正求解），保持世界变换不跳动。

## 动画保护机制

- **当前帧模式（默认）**：
  - 开启 **保护边界帧**（默认开启）时，自动在 `t - 1` 帧写入切换前的精确状态并设为恒定插值（`CONSTANT`），若拆分了已有贝塞尔曲线则采用 De Casteljau 精确切分左句柄，保证 `< t` 的所有整数帧与运动模糊子帧与切换前完全一致。
  - 在当前帧 `t` 将变换通道左右手柄与跨空间的跳变隔离（`FREE` 手柄），消除后续继续K帧时的贝塞尔过冲或前序漂移；约束影响权重自动记录为恒定插值关键帧。
  - 在场景起始帧（且此前无前置关键帧）切换时，不会在起始帧之前生成多余关键帧。
- **帧范围保持动画模式**：
  - 在指定的 `[起始帧, 结束帧]` 区间内切换子级约束权重，并逐帧反解连续的局部位置与旋转（含欧拉角连续性与四元数同半球保护）。
  - 自动保护区间外侧边界（`起始帧 - 1` 与存在后续关键帧时的 `结束帧 + 1`），使区间前、区间内、区间后的世界空间视觉动画完整保持原样。
  - 可点击 **取所选关键帧** 或 **取场景范围** 快速填入起止帧。

## 边界与回滚保护

- 当目标带缩放变化且子级约束影响了世界缩放时，自动补偿并记录缩放通道；未改变世界缩放时不会创建多余的缩放曲线。
- 相连骨骼在子级约束未强制偏移头部时正常支持旋转空间切换。
- 尊重变换通道锁定、曲线锁定、驱动器、曲线修改器及 NLA 微调模式检查；若由于锁定、零缩放或后续覆盖型约束导致无法达到目标世界变换，操作会自动取消并完整恢复原状态，不残留半成品关键帧。所有成功切换均支持 `Ctrl+Z` 撤销与重做。
