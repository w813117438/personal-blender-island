# blender-island v0.1.3 — 插入 / 移除中间帧

基于 Blender 5.3.0 Alpha，新增内置的动画时间间隔调整工具，无需安装或启用插件。
v0.1.3 是此次发布包的修订号，程序内部品牌名称仍显示 blender-island v0.1。

## 新增功能

- 时间轴、摄影表和曲线编辑器顶栏新增 **中间帧** 入口；也可在 **N → 动画工具** 打开，3D 视口同样提供侧栏面板。
- 设置帧数后，可在当前帧所在的关键帧间隔插入或移除空白时间，右侧关键帧随之移动。
- 选择 **所选关键帧之间**，可逐段调整多个关键帧之间的间隔，后续动画累计顺延。例如第 1、5、9 帧之间各插入 2 帧，结果为第 1、7、13 帧。
- 支持编辑器可编辑曲线、所选物体、所选姿态骨骼（含自定义属性），以及整个场景的活动动作。
- 移除时根据可用空白时间限制收紧量，避免重叠或丢失关键帧。保留关键帧数值、插值类型与手动控制柄，自动控制柄由 Blender 重新计算。
- 支持撤销和重做；帧数、方式和范围随场景保存。

保留 v0.1.2 的手指 Picker，以及曲线显示优化、控制柄设置、世界变换吸附、摄影表分组、智能约束和智能旋转转换。

## 下载使用

下载 `blender-island-v0.1.3-windows-x64.zip`，完整解压后运行 `blender-island.exe`。
程序、Python、运行库和内置脚本均包含在包内，无需源码目录。
使用 Blender 默认操作方案和干净的出厂偏好，独立配置位于 `portable/config`，不包含作者的个人配置。

附带 `.sha256` 文件用于校验下载；包内 `version.json` 记录完整源码提交、编译标识和程序 SHA256。
中间帧用法见 `docs/INBETWEEN.md`，手指 Picker 用法见 `docs/FINGER-PICKER.md`。

## 使用范围

中间帧工具目前处理活动 Action 的 F-Curve 关键帧，不调整 NLA 条带、驱动器、蜡笔曝光帧、音频、时间标记或播放范围。
NLA 微调模式会取消操作；锁定曲线、锁定通道组和只读动作会跳过。
共享同一动作槽位的物体仍共享修改，与 Blender 原有共享数据行为一致。

同时检查完整编译产物的后台启动、默认 Blender 键位、内置脚本与源码一致性、编译提交标识和 ZIP 的逐文件 CRC 完整性。
