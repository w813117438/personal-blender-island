# 智能约束

物体和姿态骨骼均可在“添加约束 → 关系 → 智能约束”中添加，目标可以是物体或骨骼。它不修改父子层级。

选择目标时记录当前相对变换，初次关联不跳动。改变权重时保留这一瞬间的世界变换，并重新记录跟随基准：

- 权重 1：跟随目标之后的位置、旋转和缩放变化。
- 权重 0：保留解除时的变换作为基础，不再跟随目标；仍可手动调整或播放自身动画。
- 中间权重：混合新的基础变换和目标的跟随结果。
- 再次启用：从当前状态建立新的相对关系，不返回最初的绑定位置。

切换自动记录两条关键帧通道：“影响”（权重）和“智能约束切换状态”（相对变换快照编号）。默认恒定插值，避免开关前的帧提前变化；中间权重控制跟随程度。可修改权重通道的插值，但切换状态必须保持恒定插值。移动、复制或删除一次切换时，这两条通道的对应关键帧需要一起操作。快照数据随 `.blend` 保存，正常求值不会累积上次播放的状态，因此支持倒放、跳帧和重新打开。

记录的是此约束在约束堆栈中的输入和输出，不烘焙物体或骨骼的原有变换动画。后续约束仍可能改变最终可见结果。已经记录的快照不会因为事后改动目标过去的动画或移动切换关键帧而自动重算，需要在新的切换帧重新设置权重以记录新的相对状态。直接修改曲线数据或用驱动器改变权重不会创建新快照。零缩放导致矩阵不可逆时不创建切换。关闭约束的眼睛图标或删除约束会绕过整个约束，包括解除时保留的偏移；解除跟随请使用权重 0。
