# blender-island v0.1.6 — 曲线编辑器仅选中关键帧显示控制杆

优化 **动画曲线编辑器（Graph Editor）** 的贝塞尔关键帧控制杆显示与选择防误触交互：全局默认仅在选中关键帧时显示并允许操作其曲线控制杆，避免多曲线或密集关键帧下误点、误框选未选关键帧的控制柄。
v0.1.6 是此次发布包的修订号，基于 Blender 5.3.0 Alpha，程序内部品牌名称仍显示 blender-island v0.1。

## 更新内容

- **默认仅显示所选关键帧控制杆（防误触）**：新建曲线编辑器、出厂默认工作区以及首次打开既有 `.blend` 工程时，自动启用 **仅所选关键帧的控制柄**（`use_only_selected_keyframe_handles`）。未选中的关键帧不再显示左右控制杆，也不会响应针对控制柄位置的误点击或误框选；点击或框选关键帧点后即刻显示控制杆供调节。
- **尊重手动偏好保存**：通过内部一次性迁移标记区分旧文件首次升级与用户手动设置；若在某个工程中主动关闭该选项并保存，重新打开时会保留关闭状态，不会被强行覆盖。
- **取消选中关键帧同步清理控制柄**：修复开启“仅所选关键帧的控制柄”时使用 `Shift+点击` 或 `Ctrl+框选` 取消选中关键帧中心点会残留已选左右控制柄的问题，防止取消选中后控制杆仍悬空显示或被后续 `G` / `R` / `S` 变换误带动。
- **曲线编辑器顶栏快捷开关**：除保留 **视图 → 仅所选关键帧的控制柄** 菜单项外，在曲线编辑器顶部标题栏新增 **显示控制柄** 与 **仅所选关键帧的控制柄** 紧凑图标开关，便于随时一键切换显示模式。

保留此前的子级约束空间切换、游标世界位置与旋转吸附（含简体中文菜单）、中间帧工具、手指 Picker、智能约束、智能旋转模式转换及变换通道单选独显等全部自定义动画功能。

## 下载使用

下载 `blender-island-v0.1.6-windows-x64.zip`，完整解压后运行 `blender-island.exe`。
曲线控制杆快捷开关位于 **曲线编辑器顶部标题栏**（或 **视图 → 仅所选关键帧的控制柄**）。
程序、内置脚本与简体中文语言包已包含在包内，无需额外安装插件。

使用 Blender 默认操作方案和干净的出厂偏好，独立配置保存在 `portable/config`。
附带 `.sha256` 校验文件，包内 `version.json` 记录完整源码提交、编译标识和程序 SHA256。
详细用法见 `docs/TRANSFORM-CHANNELS-AND-HANDLES.md`、`docs/CHILDOF-SPACE-SWITCH.md`、`docs/CURSOR-WORLD-SNAP.md` 和 `docs/INBETWEEN.md`。
