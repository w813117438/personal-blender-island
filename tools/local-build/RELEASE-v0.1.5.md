# blender-island v0.1.5 — 子级约束空间切换与游标吸附汉化

新增内置 **子级约束空间切换（Space Switch）** 及原生“影响（Influence）”滑条无跳变自动补偿，并补齐 3D 游标世界位置与旋转吸附菜单项的简体中文显示。
v0.1.5 是此次发布包的修订号，基于 Blender 5.3.0 Alpha，程序内部品牌名称仍显示 blender-island v0.1。

## 更新内容

- **子级约束一键空间切换（保持世界变换）**：在 **属性 → 约束 → 子级约束（Child Of）** 面板以及 3D 视口、摄影表、曲线编辑器的 **N → 动画工具 → 子级约束空间切换** 中提供 **跟随 (1)**、**松开 (0)**、多父级 **接管跟随** 与自定义目标权重切换，切换后保持物体或姿态骨骼求值后的世界位置和世界旋转不变。
- **原生“影响”滑条与 `×` 按钮直连补偿**：直接拖动或输入修改子级约束自带的 **影响（Influence）** 滑条，或点击原生关闭并保持变换（`×`）按钮时，自动反解局部变换以保持当前世界空间；原有子级约束控件（目标、设置逆矩阵、清除逆矩阵等）完整保留。
- **保护相邻关键帧与区间烘焙**：**当前帧切换** 默认在前一帧自动写入保护关键帧并冻结切线控制柄，不破坏既有关键帧曲线与后续动画；**帧范围保持动画** 支持对选定帧区间逐帧反解烘焙并保护起止边界帧。
- **关联覆盖（Library Override）与框选骨骼支持**：支持关联覆盖骨架（如角色与武器绑定）及姿态模式下框选多根骨骼时的子级约束识别与空间切换，自动跳过未指定目标的空子级约束。
- **游标世界吸附菜单汉化**：修复 `Shift+S` 饼菜单与 **物体／姿态 → 吸附** 菜单中 `Operator` 翻译上下文缺失问题，现完整显示简体中文 **选中项 -> 游标 (世界位置和旋转)** 与 **游标 -> 选中项 (世界位置和旋转)**。

保留此前的中间帧工具、手指 Picker、智能约束、智能旋转模式转换及变换控制柄偏好设置等全部自定义动画功能。

## 下载使用

下载 `blender-island-v0.1.5-windows-x64.zip`，完整解压后运行 `blender-island.exe`。
子级约束空间切换位于 **属性 → 约束 → 子级约束** 面板或 **N → 动画工具 → 子级约束空间切换**；游标世界吸附位于 3D 视口 `Shift+S` 吸附菜单。
程序、内置脚本与简体中文语言包已包含在包内，无需额外安装插件。

使用 Blender 默认操作方案和干净的出厂偏好，独立配置保存在 `portable/config`。
附带 `.sha256` 校验文件，包内 `version.json` 记录完整源码提交、编译标识和程序 SHA256。
详细用法见 `docs/CHILDOF-SPACE-SWITCH.md`、`docs/CURSOR-WORLD-SNAP.md` 和 `docs/INBETWEEN.md`。

## 使用范围与验证

子级约束空间切换支持物体与姿态骨骼的可编辑活动 Action 曲线及关联覆盖骨架；相连骨骼（Connected）仅补偿旋转，锁定通道、F-Curve 驱动器、只读动作及 NLA 微调模式会按安全规则跳过或取消并回滚。脚本在后台直接赋值 `constraint.influence` 仍保持 Blender 原生数据语义。

发布前已验证物体与姿态骨骼单／多父级切换、原生“影响”滑条连续拖动、欧拉／四元数／轴角连续性、关联覆盖双手持枪绑定（含框选骨骼与空目标兄弟约束）、游标世界吸附简体中文菜单翻译及全部原有功能回归测试，并校验发布包独立启动、内置脚本一致性、编译提交标识与 ZIP 逐文件 CRC 完整性。
