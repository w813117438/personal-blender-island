# blender-island v0.1.1 — 5.3 交互更新

基于 Blender 5.3.0 Alpha，将 4.2 个人版后续的交互优化同步到 5.3。
v0.1.1 是此次发布包的修订号，程序内部品牌名称仍显示 blender-island v0.1。

## 更新内容

- 曲线编辑器没有选中左侧通道时，显示全部正常可见曲线。
- 只有左侧通道列表的选择操作改变曲线显示范围；画布点击曲线、选择或取消关键帧不会触发独显。
- 关闭在视口内右键控制柄弹出的自定义设置菜单。右键左侧变换工具仍可调整速度（0.1–1）和大小（1–2）。
- 保留世界位置／旋转吸附、摄影表变换分组、智能约束及整数帧智能旋转转换。

## 下载使用

下载 `blender-island-v0.1.1-windows-x64.zip`，完整解压后运行 `blender-island.exe`。
包内包含运行库，无需源码目录。使用 Blender 默认操作方案及出厂偏好设置，配置独立保存在 `portable/config`，不包含作者的个人配置。

附带 `.sha256` 文件用于校验压缩包；`version.json` 记录对应的完整源码提交和程序 SHA256。
程序和 Blender Python API 的兼容版本仍为 5.3，不是将 Blender 4.2 内核打包进 5.3。

## 验证

71 项回归测试通过：曲线显示 15 项、控制柄偏好 3 项、世界吸附 27 项、智能约束 13 项、智能旋转转换 13 项。
智能约束仍按切换时记录的相对变换快照工作；修改过去的目标动画不会自动重建已有绑定。
