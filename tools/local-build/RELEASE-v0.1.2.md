# blender-island v0.1.2 — 手指 Picker

基于 Blender 5.3.0 Alpha，新增内置的通用手指骨骼选择面板。
v0.1.2 是此次发布包的修订号，程序内部品牌名称仍显示 blender-island v0.1。

## 新增功能

- 3D 视口按 **N → 手指选择 → 手指 Picker** 打开。页签不会再被翻译成“孤岛”，未选骨架时也可见。
- 左右手各有五指、每指三个可手动绑定的位置，不依赖骨骼命名规则。
- 开启“绑定模式”后点击数字按钮，搜索控制骨骼并确认；留空确认可清除绑定。
- 支持单节、整指、整手选择，Shift／加选按钮添加选择，Ctrl 减选。
- 尊重隐藏、骨骼集合及禁止选择状态；空或失效绑定不会清除原选择。
- 每个骨架物体分别保存绑定，随 `.blend` 文件保存重开；面板只负责选择，不改变姿势或插入关键帧。

保留 v0.1.1 的曲线编辑器显示优化、控制柄大小与速度设置，以及世界变换吸附、摄影表分组、智能约束、智能旋转转换。

## 下载使用

下载 `blender-island-v0.1.2-windows-x64.zip`，完整解压后运行 `blender-island.exe`。
程序、Python、运行库及脚本均已包含，无需源码目录或额外安装插件。
使用 Blender 默认操作方案及干净出厂偏好，便携配置位于 `portable/config`，不包含作者的个人配置。

附带 `.sha256` 校验文件；包内 `version.json` 记录源码提交和程序校验值，`docs/FINGER-PICKER.md` 提供使用说明。
